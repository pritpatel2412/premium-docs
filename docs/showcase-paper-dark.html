Architecture Components

The system is structured into four decoupled layers for resilient execution:

1. Content Authoring (Lean MD)
Agents author standard Markdown with YAML front matter and Docusaurus-style container blocks. Zero style pollution in prompt context.
2. In-Memory Converter
A deterministic single-pass AST preprocessor that parses nested containers and inlines syntax tokens via Pygments.
3. Self-Contained Shell
Embeds CSS custom properties, SVG symbols, and client JS directly into one standalone HTML file with strict CSP headers.

Semantic Callouts

System Information
All stylesheets and assets are bundled directly into the output file. No runtime CDN requests or external tracker beacons are executed.
Optimization Tip
Enable the sticky TOC for documents longer than 1,000 words to provide readers effortless keyboard and scroll navigation.
Deprecation Notice
The legacy single-file `.agent/` configuration will be retired in v0.3. Use the standardized `.agents/skills/` directory tree.

Implementation Profiles

The build engine runs on Python 3.9+ using standard libraries and Python-Markdown. It handles recursive container trees and strict line-level error reporting.

The Agent Skill is packaged under skills/premium-docs/ with a concise SKILL.md under 500 lines adhering to progressive disclosure guidelines.

The cross-platform installer install.py sets up symlinks or directory copies for Antigravity, Claude Code, Cursor, Gemini CLI, and other agent platforms.

Frequently Asked Questions

Does this document require internet access to view?

No. All styling, SVG icons, fonts, and client scripts are directly embedded into the single HTML file. You can open it offline, attach it to emails, or host it on any static server.

How does dark mode persist across reloads?

The mode setting is stored in local storage inside a safe try-catch wrapper. If local storage is disabled (e.g. in high-security iframe sandboxes), it gracefully defaults to the operating system's prefers-color-scheme.
