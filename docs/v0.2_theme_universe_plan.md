# Implementation Plan: premium-docs v0.2 "Theme Universe"

## 1. Executive Summary & Architecture
Transform `premium-docs` into an expansive theme ecosystem delivering **240+ verified premium themes**, featuring a signature hand-drawn **Sketch** family (whiteboard/Excalidraw feel), while guaranteeing 100% offline self-containment, WCAG AA compliance, and strict token-budget efficiency.

### Core Formulation: Data-Driven Theme Generation
$$\text{Theme} = \text{Palette} \ (\text{DTCG } .tokens.json) \times \text{Style Family} \ (\text{CSS Layers}) \times \text{Type Pack} \ (\text{Fonts / Stacks})$$

- **Tier S (>= 30)**: Hand-tuned signature themes with unique component touches, micro-textures, and bespoke styling.
- **Tier A (>= 210)**: Curated, mathematically contrast-verified pairings auto-generated from quality-filtered palettes and family definitions.
- **Tier B ($\infty$)**: Combinatorial on-demand pairing via `--style <family> --palette <palette>` validated at build time.
- **Agent Footprint**: `themes/index.json` (< 100 KB) is the **only** file an AI agent inspects in-context; CLI helper `scripts/themes.py` provides natural-language search, semantic filtering, and mood picking.
- **Installed Skill Budget**: Total installed skill directory <= 3.0 MB. Dev tools (`tools/`) and vendor snapshots (`vendor/`) remain dev-only.

## 2. Phase 0: Verification & Legal Manifest

### 2.1 Excalifont & Typography Verification
- **Excalifont**: Sourced from official Excalidraw repository (`excalidraw/excalidraw`).
  - License: SIL Open Font License, Version 1.1 (OFL-1.1).
  - Reserved Font Name (RFN): Excalidraw declares "Excalifont" as its trademark/font name; when unmodified, OFL allows bundling and embedding. If subsetted, OFL requires derivative naming unless RFN is waived.
  - Alternative / Fallbacks: `Caveat`, `Kalam`, `Patrick Hand` (OFL from Google Fonts, verified No Reserved Font Name).
- **Humanist Reading Sans**: `Inter` / `Nunito` / `Work Sans` (OFL, verified).
- **Serif / Editorial**: `Fraunces` / `Playfair Display` / `Merriweather` (OFL).
- **Monospace**: `JetBrains Mono` / `Fira Code` / `Space Mono` (OFL / Apache 2.0).
- **Pixel**: `Press Start 2P` / `Silkscreen` (OFL).
- **System Fallback Stacks**: Full multi-script support including Indic scripts (`Noto Sans`, `Nirmala UI` for Hindi and Gujarati) to prevent mojibake.
- **Manifest Location**: `vendor/fonts/MANIFEST.json` recording `name`, `version`, `license`, `rfn_status`, `source_url`, and `sha256`.

### 2.2 Rough.js Pinning
- **Version**: `roughjs@4.6.6` (latest stable 4.x).
- **License**: MIT (`rough-stuff/rough`).
- **Vendoring**: Browser-standalone UMD bundle in `vendor/rough/rough.min.js` (~9 KB gzipped).

### 2.3 Tinted-Theming Schemes
- **Source**: `tinted-theming/schemes` (formerly `base16-schemes`).
- **License**: MIT License.
- **Isolation**: Parse YAML directly using custom Python tools (`tools/import_schemes.py`). Zero code copied from GPL-3.0 tinted builder utilities.

### 2.4 Antigravity Paths
- Verified consistent with v0.1:

## 3. Phase-by-Phase Roadmap & Checkpoints

### Phase 1: Engine Refactor & CSS Layer Contract (Commit & Checkpoint 1)
- Extend `--pd-*` design token contract across:
  - Colors (`--pd-bg`, `--pd-surface`, `--pd-surface-2`, `--pd-border`, `--pd-text`, `--pd-text-soft`, `--pd-muted`, `--pd-accent`, `--pd-accent-soft`, `--pd-on-accent`, feedback tokens, code tokens).
  - Shapes (`--pd-radius-box`, `--pd-radius-field`, `--pd-radius-chip`, `--pd-border-width`, `--pd-border-style`).
  - Depth (`--pd-shadow-1`, `--pd-shadow-2`, `--pd-shadow-3`).
  - Textures (`--pd-texture`, `--pd-grid`, `--pd-noise`).
  - Typography (`--pd-font-display`, `--pd-font-body`, `--pd-font-mono`, `--pd-size-base`, etc.).
  - Layout (`--pd-measure`, `--pd-density`, `--pd-toc-style`).
- Restructure CSS into cascade layers:
  `@layer pd-reset, pd-base, pd-components, pd-family, pd-palette, pd-user;`
- Migrate existing 3 themes (`aurora`, `slate`, `paper`) into `.tokens.json` palettes and `clean` / `editorial` family rules.
- **Parity Verification**: Screenshot comparison ensuring 100% visual parity with v0.1 deliverables.
- Implement agent CLI: `scripts/themes.py` (search, list, show, random, preview).

### Phase 2: Palette Pipeline & OKLCH Gamut Adjuster (Commit & Checkpoint 2)
- Build `tools/import_schemes.py`:
  - Pure Python stdlib OKLab / OKLCH converter and contrast solver (`ensure_contrast(fg, bg, target_ratio)`).
  - Lightness-only adjustment preserving hue and chroma.
  - Standards: Body text >= 4.5:1 (targeting 7:1 where feasible), muted text >= 4.5:1, accents on bg >= 4.5:1, borders >= 3.0:1.
  - Contrast audit log & fidelity tracking in `themes/audit/adjustments.json`.
  - De-duplication using OKLab triplet $\Delta E$ distance.
- Import >= 150 community base16/base24 palettes.
- Author >= 24 original MIT palettes, including:
  - `Ember` (brand identity: #0A0F2E, #26308A, #FDE047, #FB923C, #F43F5E).
  - Indian landscape & textile collection (`Bandhani Indigo`, `Saffron Dawn`, `Monsoon Slate`, `Chai Spice`, `Rann White`, `Gulal Rose`, `Malabar Coast`, `Jaipur Terra`, `Nilgiri Mist`, `Kutch Camel`).
- Light/Dark pairing mapping in `themes/pairings.json`.
- Output: `themes/palettes/*.tokens.json` in DTCG 2025.10 format.

### Phase 3: The Sketch Family (Hero Feature) (Commit & Checkpoint 3)
- Deliver the hand-drawn whiteboard / Excalidraw aesthetic:
  - **L0 (No-JS / Fallback / Print)**: 8-variant deterministic CSS wobble border-radius via element hash. Opaque paper surfaces behind all text. Solid crisp focus rings.
  - **L1 (Rough.js Interactive Enhancement)**: `assets/js/sketch.js` utilizing `vendor/rough/rough.min.js`.
    - Detects `[data-pd-rough]` nodes.
    - Deterministic SVG geometry (rectangles, ellipses, hachure lines, zigzags).
    - Under-text positioning (`aria-hidden="true"`, `pointer-events: none`).
    - Debounced ResizeObserver + IntersectionObserver lazy rendering (< 150ms total draw budget).
    - Performance ceiling: automatic fallback to L0 if rough elements exceed 400.
  - Hand-drawn heading underlines, `==marker highlights==`, sketchy callouts, rough table borders, rough code frames, doodle step arrows.
  - New universal components: `:::sticky`, `:::flow`, `==highlight==`, `:::annotation`.
  - Ship at least 12 Sketch themes across whiteboard, kraft paper, dark board, blueprint-sketch, and curated palettes.
  - Multi-viewport visual QA at 1440px, 768px, 375px; print mode and JS-disabled mode verification.

## 4. Quality Gates & Automated Verification
- **Automated Audit Tool (`tools/audit_themes.py`)**:
  - Headless browser audit across all gallery themes in light and dark modes at 1440px, 768px, and 375px.
  - Computed-style contrast calculation of actual rendered text against composited backgrounds.
  - Perceptual hash ($\le 92\%$ visual similarity threshold) to guarantee theme distinctness.
  - Zero console errors, zero external network requests.

  - Grid PNG compilation for rapid human visual review.
